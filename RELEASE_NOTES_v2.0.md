# AdvancedExcel v2.0.0 Release Notes

**Release Date:** (to be filled when published)

This is a **major** release containing breaking API changes. The previous stable state is preserved as tag `v1.0.0`.

## Highlights

- Complete migration from camelCase to PEP 8 `snake_case` method names
- Modern Python package structure (`advanced_excel`)
- First-class support for realistic complex Excel test fixtures
- Full test suite green with both synthetic and real-file tests
- Cleaner packaging and better developer experience

## Breaking Changes

All public methods have been renamed:

| Old (v1.x)                        | New (v2.0+)                          |
|-----------------------------------|--------------------------------------|
| `getSheet`                        | `get_sheet`                          |
| `getSheetNames`                   | `get_sheet_names`                    |
| `getNextValue`                    | `get_next_value`                     |
| `getDataFrameBlocksByKeyName`     | `get_dataframe_blocks_by_key_name`   |
| `removeEmptyRows`                 | `remove_empty_rows`                  |
| `removeDuplicates`                | `remove_duplicates`                  |
| `setRowAsHeader`                  | `set_row_as_header`                  |
| `mergeRows` / `mergeColumns`      | `merge_rows` / `merge_columns`       |
| `replaceNaNStrings`               | `replace_nan_strings`                |
| `caseColumnValues`                | `case_column_values`                 |
| ... (and many more)               | ...                                  |

**Import change** (recommended):

```python
# Recommended in v2.0+
from advanced_excel import AdvancedExcel
```

The old import style may still work in some environments for compatibility but is no longer the primary supported path.

## New Features

- **Real reference Excel test fixtures**
  - `tests/data/multi_table_studies.xlsx`
  - `tests/data/complex_key_blocks.xlsx`
  - Generated by `tests/generate_fixtures.py`
  - Cover multiple tables per sheet, repeated keys ("Batch Number"), key-value extraction, mixed data, etc.

- **New integration tests** that exercise the library against the real reference files.

- **Context manager support**:
  ```python
  with AdvancedExcel("file.xlsx") as ae:
      sheet = ae.get_sheet("Data")
  ```

## Improvements

- Modern `pyproject.toml`-based packaging with proper extras (`[sspipe]`, `[dev]`)
- Significantly improved test coverage for complex real-world Excel scenarios
- Various robustness and performance improvements in block extraction, pair values, row/column operations, etc.
- Many latent bugs fixed during the refactoring (e.g. `merge_rows` separator logic)
- Updated and cleaned README with working examples

## Migration Guide

See the PR description or the top of the README for the full migration table.

The high-level concepts (block extraction, key localization, DataFrame pipelines, sspipe chaining) remain the same — only the method names changed.

## What's Next

This release lays a clean foundation. Future work can focus on:
- Richer Table/Entity return types
- Better merged cell / formula handling
- More advanced Excel features (styles, charts, etc.)
- Performance for very large files

## Thanks

Special thanks to everyone who has used AdvancedExcel for complex real-world data extraction tasks. This v2.0 release makes the library much more maintainable and better tested against the kinds of messy multi-table Excel files it was originally designed to handle.
