## Summary

This PR delivers **v2.0.0** of AdvancedExcel — a major release with a modernized, Pythonic API and significantly improved test coverage using real-world complex Excel files.

### Breaking Changes (why v2.0)

- All public methods have been renamed from camelCase to PEP 8 `snake_case`:
  - `getSheet` → `get_sheet`
  - `removeEmptyRows` → `remove_empty_rows`
  - `getDataFrameBlocksByKeyName` → `get_dataframe_blocks_by_key_name`
  - `setRowAsHeader` → `set_row_as_header`
  - `mergeRows` / `mergeColumns` / etc.
  - Full list of changes is in the commit history.

- The package is now properly structured as `advanced_excel` (lowercase, standard Python package layout) instead of the previous `AdvancedExcel` top-level module. Recommended import:

  ```python
  from advanced_excel import AdvancedExcel
  ```

Because these are breaking API changes, the version has been bumped to **2.0.0**.

The previous stable state has been preserved as tag `v1.0.0`.

### New Features & Major Improvements

- **Realistic test fixtures with complex Excel files**
  - Added `tests/data/multi_table_studies.xlsx` and `tests/data/complex_key_blocks.xlsx`
  - Generated by the new `tests/generate_fixtures.py` script
  - These files contain:
    - Multiple tables/blocks per sheet separated by repeated keys ("Batch Number")
    - Scattered key-value pairs ("Study No", "Plan No", "Instrument", etc.)
    - Header rows, data tables, NaN/"tbd" values, empty areas
  - New integration-style tests (`test_real_multi_table_studies`, `test_real_complex_key_blocks`) that load the real files and exercise:
    - `get_dataframe_blocks_by_key_name`
    - `get_next_value` (key localization)
    - `get_all_pair_values`
    - `get_all_tables`
    - Cleaning/reshape pipelines on extracted data

- **Full test suite is now green** (including the new real-file tests + all previous synthetic coverage).

- **Package & tooling modernization**
  - Switched to `pyproject.toml` (modern packaging)
  - Clean dependency split (core vs optional `[sspipe]` and `[dev]`)
  - Proper editable install support (`pip install -e .`)
  - Added context manager support (`with AdvancedExcel(path) as ae:`)

- **Code quality & robustness**
  - Many methods now use more efficient pandas patterns
  - Fixed latent bugs (e.g. `merge_rows` separator handling)
  - Better handling of edge cases in block extraction and pair values
  - Updated to current best practices (ruff, black, etc.)

- **Documentation**
  - README fully updated with working snake_case examples
  - Clear migration notes for the v1 → v2 breaking changes

### Migration from v1.x

Replace all method calls:

```python
# Old (v1)
data.getSheet("Sheet1")
data.removeEmptyRows(df)
data.getDataFrameBlocksByKeyName(df, "Batch Number")
data.setRowAsHeader(df, 0)

# New (v2)
data.get_sheet("Sheet1")
data.remove_empty_rows(df)
data.get_dataframe_blocks_by_key_name(df, "Batch Number")
data.set_row_as_header(df, 0)
```

The class name `AdvancedExcel` and the high-level concepts remain the same.
